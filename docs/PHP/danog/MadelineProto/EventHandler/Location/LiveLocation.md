# `danog\MadelineProto\EventHandler\Location\LiveLocation`
[Back to index](../../../../index.html)

> Author: Daniil Gentili <daniil@daniil.it>  
  

Represents a live location, which the sender updates by editing the message until it expires  



## Properties
* `$period`: `int` For how long (in seconds) the location is updated, starting from the date of the message; 0x7fffffff for an indefinite period
* `$heading`: `?int` Direction in which the sender is moving, in degrees (1-360)
* `$proximityNotificationRadius`: `?int` The sender is notified when another user comes closer than this distance, in meters
* `$geo`: `danog\MadelineProto\EventHandler\Media\GeoPoint` The geo point
