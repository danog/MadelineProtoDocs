Back to index

Author: Daniil Gentili daniil@daniil.it

The group call has started or ended.

Properties

  • $duration: ?int Group call duration
  • $callId: int Group call ID

  • $id: int Message ID

Get replied-to message.

May return null if the replied-to message was deleted, if it is in another chat we can’t access, or if the message

reply(string $message, \danog\MadelineProto\ParseMode $parseMode = \danog\MadelineProto\ParseMode::TEXT, (array|null) $replyMarkup = NULL, (integer|string|null) $sendAs = NULL, (integer|null) $scheduleDate = NULL, boolean $noWebpage = false, boolean $silent = false, boolean $noForwards = false, boolean $background = false, boolean $clearDraft = false, boolean $updateStickersetsOrder = false, ?\Amp\Cancellation $cancellation = NULL, (integer|string|null) $peer = NULL): \danog\MadelineProto\EventHandler\Message

Reply to the message.

Parameters:

  • $message: string Message to send
  • $parseMode: \danog\MadelineProto\ParseMode Parse mode
  • $replyMarkup: (array|null) Keyboard information.
  • $sendAs: (integer|string|null) Peer to send the message as.
  • $scheduleDate: (integer|null) Schedule date.
  • $noWebpage: boolean Set this flag to disable generation of the webpage preview
  • $silent: boolean Whether to send the message silently, without triggering notifications.
  • $noForwards: boolean Only for bots, disallows further re-forwarding and saving of the messages, even if the destination chat doesn’t have content protection enabled
  • $background: boolean Send this message as background message
  • $clearDraft: boolean Clears the draft field
  • $updateStickersetsOrder: boolean Whether to move used stickersets to top
  • $cancellation: ?\Amp\Cancellation
  • $peer: (integer|string|null) Chat to send the reply to: by default the chat of this message, another chat for a cross-chat reply.
